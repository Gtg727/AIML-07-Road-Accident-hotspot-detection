# AIML-07-Road-Accident-hotspot-detection

System Outputs:

- Risk Level (Low / Medium / High)
- Risk Score (0–100)
- Model Confidence %

---

## 🖥 User Interface

The system accepts:

- Weather Condition
- Traffic Density
- Time of Day
- Road Type

Returns:

- Risk Score (0–100)
- Risk Level Classification
- Confidence %

Designed for:

- Government dashboards
- Route risk advisory systems
- Road safety planning tools
